# Motrix 音视频合并插件

[English](README.md)

官方按需安装插件（`motrix.media-merge`），默认不随 Motrix 安装。将一个文件的第一条视频轨和另一个
文件的第一条音频轨合并，直接复制媒体轨道，不重新编码。支持 MP4、MKV 输出，也支持
仅包含音轨的 MP4 输入。输入顺序明确反转时会自动识别并交换。

## 使用要求

- **Motrix 2.0.0-beta.48 及以上、低于 3.0.0**，并具备插件操作 v1、可组合 UI、所选文件授权和操作上下文媒体能力。beta.48 是计划中的首个支持版本，机制和插件仍未发布；若宿主功能延期，签名前必须同步提高包与注册表的最低版本。beta.47 会被拒绝，包括版本号仍为 beta.47 的开发构建。
- 在 **设置 → 集成 → 媒体工具** 中配置 FFmpeg。修改 FFmpeg 配置后请重新启用插件。

## 使用方法

正式签名包发布后，可从 [插件目录](https://motrix.app/zh/plugins/motrix.media-merge/) 安装并启用。使用 `motrix.*` 命名空间的本地包同样需要有效官方签名才能安装。随后可以选中两个
已完成的单文件下载任务，选择 **合并音频和视频**；也可以进入本插件详情的 **操作**
页，直接选择本地文件。操作页和任务菜单弹窗共用表单，切换 Tab 会保留选择。填写新的 `.mp4` 或 `.mkv` 输出文件名后点击 **合并**。

点击 **再次合并** 会清空视频、音频、输出位置和上次结果，保留所选 MP4/MKV 格式。新一轮需要重新选择文件，不会再次填入上次选中的下载任务。

进度、取消、临时文件和不覆盖的输出保存由宿主管理。源文件保持不变，宿主先为所选输入建立快照，再以原子方式保存结果且不覆盖已有文件。目标文件系统必须支持私有目录和原生无覆盖发布；不满足保证时会拒绝执行。Web UI 复用服务器文件浏览器选择输入和新的输出文件名，并受服务器下载目录策略约束；
不会上传浏览器所在电脑的文件。

本插件不做片段首尾拼接、音画偏移调整或不兼容编码的转码，也不在下载后自动执行。
若 MP4 不支持当前编码，可尝试 MKV。

输入必须是独立的媒体文件（MP4/MOV、MKV/WebM、AVI、MPEG/TS、FLV、AAC、MP3、
FLAC、Ogg 或 WAV）。播放列表、concat 脚本和图片序列会在探测或合并前被拒绝，
即使它们引用的也是本地文件。宿主要求绝对路径，并在解析符号链接后检查目录权限；
文件内部的相对引用不会继承该文件的授权。

## 开发

在仓库根目录执行以下命令。插件使用仓库统一的构建、打包和签名发布流程；不要将它加入 Motrix 的 `scripts/builtins.lock.json`。

```sh
pnpm install
pnpm --filter motrix-builtin-media-merge typecheck
pnpm test
pnpm lint
node scripts/pack.mjs motrix.media-merge
```

插件通过 `contributes.operations` 声明界面，通过 `commands.registerOperation`
注册私有处理命令，申请 `ffmpeg`、`files.selected.read` 和 `files.selected.write`。
声明权限不等于获得任意文件访问能力：宿主将用户选择得到的不透明文件引用绑定到单次操作。
插件不申请网络权限，也不注册下载任务生命周期 Hook。

处理函数接收 `{ videoInput, audioInput, format, output }`，通过 `context.media.probe`
探测输入，自动交换明确选反的轨道，等待 `context.media.mergeStreams` 完成，
再返回已授权的输出引用。宿主校验结果并保存文件。普通命令及跨插件调用均不能调用此操作。
表单、多语言文案、入口和业务错误由插件清单定义，无需宿主提供媒体专用界面。

每个输入最多 8 GiB，单次操作总输入最多 16 GiB。输入快照和输出暂存需要足够磁盘空间。
取消时先停止宿主管理的任务，再清理临时资源；关闭表单不会中止任务。
宿主重启会中断操作，不会自动重放合并。
